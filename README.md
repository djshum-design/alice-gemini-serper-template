# Алиса + GPT 6.1 SOL через NordRouter

Навык «Джарвис сан» использует `openai/gpt-6.1-sol`. Ключ хранится в Vercel как `NORDROUTER_API_KEY` (Production). В коде и архиве секретов нет.

## Использование

После публикации на устройстве с аккаунтом владельца Яндекса: «Алиса, запусти навык Джарвис сан».
Задайте вопрос. Навык сразу сообщает об ожидании. Через несколько секунд скажите «Готово?». Проверка готовности не создаёт новый запрос к GPT. «Отмена» сбрасывает ожидание, но не отменяет уже запущенную генерацию.

## Подключение

Webhook: `https://alice-gemini-serper-template-seven.vercel.app/api`.
Обязательная переменная: `NORDROUTER_API_KEY`. Необязательные: `NORDROUTER_MODEL`, `SERPER_API_KEY`.
Поиск актуальной информации отключён без ключа Serper.

## Почему используется ожидание

Алиса принимает ответ в течение 4,5 секунды. GPT может работать дольше, поэтому `waitUntil` продолжает запрос после ответа webhook, а временный результат сохраняется в Vercel Runtime Cache. Требуются один регион `fra1`, включённое хранилище состояния навыка и `@vercel/functions`.
Результаты привязаны к сессии через HMAC, живут до 3 минут, ожидание ограничено 2 минутами. Кэш может потерять запись раньше; в таком случае платная генерация автоматически не повторяется. История хранится в состоянии сессии Алисы.

## Проверки

`npm install` и `npm test`. Модель и кэш в тестах заменены заглушками; тесты не тратят баланс.
В живом тесте начало фонового запроса заняло 0,47 с; получение готового ответа — 0,58 с. Это измерения одного запуска, а не гарантия времени генерации модели.
