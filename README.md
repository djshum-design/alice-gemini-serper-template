# Яндекс Алиса + GPT 6.1 SOL через NordRouter

Обработчик навыка Алисы для Vercel. Модель по умолчанию: `openai/gpt-6.1-sol`, идентификатор проверен в каталоге NordRouter.

## Настройка Vercel

1. Импортируйте этот репозиторий в Vercel.
2. В Settings → Environment Variables добавьте для Production переменную `NORDROUTER_API_KEY`. Type: Secret, Value: ваш ключ NordRouter.
3. При необходимости добавьте Config-переменную `NORDROUTER_MODEL`. По умолчанию уже используется `openai/gpt-6.1-sol`.
4. Для поиска в интернете можно добавить Secret-переменную `SERPER_API_KEY`. Для обычных ответов GPT она не нужна.
5. После изменения переменных выполните Redeploy и дождитесь Ready.

Код обращается к `https://global-api.nordrouter.com/v1/chat/completions`. Ключи Google Gemini и прямого OpenAI для этой версии не нужны. Старые инструкции о GEMINI_API_KEY не применяются. Секреты храните только в Vercel, не в GitHub и не в сообщениях.

## Подключение Алисы

1. В Vercel откройте Settings → Domains и скопируйте свой Production-домен.
2. В настройках навыка Яндекс Диалогов укажите Webhook URL: `https://ВАШ-ДОМЕН/api`.
3. Включите «Использовать хранилище данных в навыке» для истории разговора.
4. Проверьте приветствие и вопрос во вкладке «Тестирование». Вопрос к GPT расходует баланс NordRouter.
5. Для голосового запуска настройте доступность навыка и используйте тот же аккаунт Яндекса на колонке. Скажите: «Алиса, запусти навык [активационное имя]».

## Проверки

GET `/api` показывает имя модели и `configured: true`, если ключ задан. Он не вызывает нейросеть и не проверяет действительность ключа. POST с пустой репликой возвращает приветствие без вызова нейросети. POST с вопросом обращается к GPT.

Алиса ждёт ответ около 4,5 секунды. Запрос к NordRouter ограничен 3 секундами, ответы краткие. При медленной генерации навык возвращает сообщение о повторной попытке; наличие модели в каталоге не гарантирует ответ в этот срок.

Для разработчиков: Node.js 22+, `node --test`. Тесты используют подменённый API и не расходуют баланс.
